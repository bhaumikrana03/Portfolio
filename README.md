# Personal Portfolio Website

A clean, modern, and fully responsive personal portfolio website designed to showcase web development projects, skills, and background. Built using semantic HTML5 and modern CSS styling.

---

## 🚀 Features

- **Hero & About Section:** Brief professional introduction and avatar/profile display.
- **Projects Showcase:** Highlights key work, project overviews, and live/source code links.
- **Skills Matrix:** Clean presentation of core technologies and development tools.
- **Contact Area:** Integrated contact information and social/networking links.
- **Responsive Design:** Optimized layout for desktops, tablets, and mobile devices.

---

## 🛠️ Built With

- **HTML5:** Semantic site structure and accessibility.
- **CSS3:** Custom layouts, responsive design, and styling.
- **Assets:** Optimized local images and profile media.
